# Praxis Windows beta

Public downloads and setup instructions for Praxis. Application source is maintained separately.

Download [Praxis 0.1.2 Windows beta](https://github.com/Yhat-Git-Org/praxis-releases/releases/tag/v0.1.2-beta.1), including the installer and **START-HERE.html**. This beta includes private in-app feedback with screenshots, report history, replies, and status. No emails are sent.

Read the [Windows setup guide](windows-beta.md) for prerequisites, sign-in, workspace setup, and troubleshooting. To upgrade, quit Praxis and install the new beta. Automatic updates are not included.

The Windows installer is unsigned. This is an early testing beta; begin with fictional client data.

Version 0.1.2 adds the CLI to your Windows user PATH and remembers the last open workspace. Close and reopen your terminal after upgrading; open your workspace once to save its location.
